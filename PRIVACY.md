# Privacy

Effective 2026-10-22. The hosted app processes pasted metadata and UI source only in the current browser tab. It has no analytics, cookies, accounts, storage, telemetry, advertising, or network API calls. GitHub Pages may process ordinary web-server request data under GitHub's policies. Closing or reloading the tab clears app state. The CLI reads only the files named on its command line and writes the report to standard output. Do not paste secrets; source files can contain them even though the app does not transmit them.
